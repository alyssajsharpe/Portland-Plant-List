## Portland Plant List
This project was built as a tool to assist volunteers that are helping verify backyards in Portland Oregon for the Backyard Habitat Certification Program. 
https://backyardhabitats.org/our-program/

As a volunteer myself, I found it challenging to memorize all of the plants right off the bat and we didn't have a easy tool to look up plants specifically for the Portland plant list other than a limited in detail spreadsheet. I gathered the plants on that spreadsheet and transformed the data into a json file that my Next.js application could ingest and easily display that information to the user. 

Images are hosted on a 3rd party hosting platform called Cloudinary, the rest of the application is built into the Next.js app and hosted using Vercel. 

Thanks for checking out my app, hopefully it can help you learn a few things about our local plants!
